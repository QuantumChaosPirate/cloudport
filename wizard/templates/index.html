Welcome to CloudPort

This wizard will guide you through setting up your personal cloud platform. The process takes about 5 minutes.

You will set up:

  • 1. Your domain and SSL certificate
  • 2. Your storage plan
  • 3. Your owner account
  • 4. Your Jellyfin media server

Azure Storage Setup

CloudPort uses Microsoft Azure to store your files securely. Enter your Azure storage details below.

You can find these in the Azure Portal under your Storage Account.

Found in Azure Portal → Storage Accounts → your account name
Found in Azure Portal → Storage Account → Access Keys → Connection String
